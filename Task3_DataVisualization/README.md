# Netflix Data Visualization Dashboard

This project is an interactive Power BI dashboard created using the Netflix Movies and TV Shows dataset.

## Tools Used

* Power BI
* Data Cleaning
* Data Visualization

## Dashboard Features

* Total Movies and TV Shows
* Top Countries by Netflix Content
* Content Release Trend
* Rating Distribution
* Interactive Filters and Slicers

## Insights

* Movies are higher in number than TV Shows.
* United States has the highest Netflix content.
* Netflix content increased rapidly after 2015.
