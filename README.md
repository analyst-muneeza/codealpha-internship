# CodeAlpha Internship Projects

This repository contains all projects completed during the CodeAlpha Data Analytics Internship.

## Projects Included

### Task 1 — Web Scraping
- Extracted quotes data from a website using BeautifulSoup
- Stored data in CSV format
- Performed basic visualization

### Task 2 — Exploratory Data Analysis (EDA)
- Cleaned and analyzed Netflix dataset
- Handled missing values
- Created visualizations and heatmaps

### Task 3 — Data Visualization Dashboard
- Built an interactive Netflix dashboard using Power BI
- Added KPIs, charts, slicers, and insights

### Task 4 — Sentiment Analysis
- Performed sentiment analysis using TextBlob
- Classified text into Positive, Negative, and Neutral sentiments
- Visualized sentiment distribution

## Tools & Technologies Used
- Python
- Pandas
- BeautifulSoup
- Matplotlib
- Seaborn
- Power BI
- TextBlob
